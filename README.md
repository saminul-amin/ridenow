# RideNow - Your Ride, Right Now

Welcome to **RideNow**, the next-generation ride-sharing platform connecting riders and drivers seamlessly. Build with speed, security, and user experience in mind.

## Features

-   **User Roles**: Dedicated dashboards for **Riders**, **Drivers**, and **Admins**.
-   **Real-time Tracking**: Interactive maps to track rides and location (implied/mocked).
-   **Ride Management**:
    -   Riders can request rides, view history, and manage their profile.
    -   Drivers can accept rides, view earnings, and manage their vehicle details.
-   **Admin Control**: Comprehensive admin dashboard to oversee users and rides.
-   **Security**: Role-based access control and secure authentication.
-   **Responsive Design**: A smooth experience across desktop and mobile devices.

## Tech Stack

This project is built using modern web technologies:

-   **Frontend Framework**: [React](https://react.dev/) (v19)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/) (v4)
-   **State Management**: [Redux Toolkit](https://redux-toolkit.js.org/)
-   **Build Tool**: [Vite](https://vitejs.dev/)
-   **Routing**: [React Router](https://reactrouter.com/) (v7)
-   **Icons**: [Lucide React](https://lucide.dev/)
